# Art pipeline

Everything under `public/worlds/` is generated by scripts in this folder. Nothing is hand-exported, so any world can be rebuilt, retuned, or regenerated at a different quality.

## One-time setup

| Tool | Where it lives | Why |
| --- | --- | --- |
| Blender 5.2 LTS | `/Applications/Blender.app` | Modeling, Cycles baking and stills, glTF export |
| Molecular Nodes (Blender extension) | installed with `Blender --online-mode --command extension install -s -e molecularnodes` | Real protein structures for the DNA world |
| KTX-Software 4.4 (`ktx`, `toktx`) | `~/.local/ktx` (extracted from the official .pkg with `pkgutil --expand-full`, no sudo) | KTX2/Basis texture compression |
| `@gltf-transform/*`, `sharp`, `geotiff` | devDependencies | GLB optimization, image conversion, DEM reading |

```bash
source art/env.sh   # sets $BLENDER, adds ktx to PATH, defines `blend <scene>`
```

## Layout

```
art/
  env.sh              paths + `blend <scene> [--steps a,b] [--variant day|night|both] [--preview]`
  build-all.sh        rebuild every world (or the ones named)
  optimize.mjs        GLB -> meshopt geometry + KTX2 textures, names preserved
  images.mjs          Cycles layer PNGs -> webp layers + composited posters; pano; lightmap clean
  fetch/              cached downloaders: polyhaven, ambientcg, pdb, geo (DEM, Sentinel-2, OSM)
  lib/ddd/            shared bpy helpers (scene, mat, geo, inflate, bake, export, rails, render)
  worlds/<scene>/     build.py (Blender) + build.sh (fetch -> blend -> optimize -> images)
  .cache/             raw downloads (gitignored)
  out/<scene>/        intermediate renders and unoptimized GLBs (gitignored)
```

## Conventions

- Author in meters, Z up. The exporters convert to three.js Y up.
- **Chapter time `s`**: a scene's camera rail is keyed in chapter units. `s = 0` is the start of the scene's first chapter, `s = 1` the start of its second, and so on. One Blender frame is `0.01` chapter. `rails.export()` samples the camera every frame into `public/worlds/<scene>/rails.json`.
- **Baking**: `bake.bake_group()` joins static objects, unwraps one atlas, bakes diffuse GI (no glossy) and rewires it as an emissive map on a black base at 2x emissive strength. Live environment reflections still work on top in three.js.
- **Low Resources layers**: `render.layers()` renders one RGBA still per depth band from a rail position. Other bands are camera-invisible but still cast shadows and reflect, so the stack recomposes exactly. `images.mjs layers <scene>` converts them and composites the posters.
- **Day and night**: every world builds both variants. Dark mode loads the night files.

## Output contract (read by `src/worlds/`)

```
public/worlds/<scene>/
  rails.json                         camera samples: { step, sMax, count, p[], q[], fov[] }
  hi/*.glb                           full-quality assets (desktop)
  lo/*.glb                           optional light assets used by the Low mode
  layers/<tag>.json                  { tag, s, fov, aspect, p, q, layers: [{ band, file, depth }] }
  layers/<tag>-<band>.webp
  posters/<tag>.webp + index.json    composited stills (reduced motion, no WebGL, loading)
```

Tags are `<variant>-<name>`, for example `day-intro`, `night-work`.

## Adding a world

1. Create `art/worlds/<scene>/build.py` (start from an existing one) and `build.sh`.
2. Run `source art/env.sh && bash art/worlds/<scene>/build.sh`.
3. Implement `src/worlds/scenes/<scene>/` against the files above.
4. Add any new data source to `src/lib/credits.ts`.
