# Everest world (scene id `everest`) for the About page

Page: `/about` (src/app/about/page.tsx, src/components/about/AboutStory.tsx, src/components/home/Testimonials.tsx). Chapters in order: intro (PageHero), values, tools, story (Then/Next/Now timeline), voices (testimonials), outro (footer). The rail covers s in [0, 6] plus margin (sMax ~6.2). Palette/label in src/lib/worlds.ts (`about`: "The long way up", "From Lukla to the summit").

The owner's exact request for this page: "Panning over the mountain ranges that include mount everest, from a birds eye altitude that shows from above the peaks looking over the 3 dimensional range that is accurately topographed, it zooms in for key parts of the main hiking treks and shows a golden line that is being drawn as you scroll for the path that hikers take up to the Everest Summit. Look online for examples and inspiration of this being done already." Inspiration already found: the Mapbox free-camera "Climbing Mt Fuji" scrollytelling uses a detailed route line for drawing plus a separate SMOOTHED spline for the camera so the flight never jitters. Do the same.

## Requirements
- Terrain from REAL elevation: the Copernicus GLO-30 tile is already downloaded at `art/.cache/geo/dem/Copernicus_DSM_COG_10_N27_00_E086_00_DEM.tif` (GeoTIFF; the `geotiff` npm package is installed; `node art/fetch/geo.mjs dem|s2|osm` fetchers exist). Crop the Khumbu region (roughly lat 27.66-28.03, lon 86.66-86.99; must include Lukla 27.687N 86.731E through the Everest summit 27.9881N 86.9250E, plus Lhotse, Nuptse, Ama Dablam 27.861N 86.861E). Convert to a local metric grid (1 unit = 100 m is a good scale; true vertical scale, optionally a subtle 1.15x exaggeration). Write a small Node script in your folder to crop/resample the DEM into a 16-bit heightmap + metadata, and build the mesh in Blender from it. Moderate-resolution mesh for hi (e.g. 512-768 grid, decimated), plus a normal map computed from the full-res DEM so ridgelines stay crisp.
- Surface: Sentinel-2 true color (`node art/fetch/geo.mjs s2 minLon minLat maxLon maxLat 2024-10-15/2024-12-31` picks the lowest-cloud scenes; you may need to mosaic/crop/reproject the visual COG with geotiff + sharp; if S2 is impractical, fall back to fully procedural). Blend it with procedural snow/rock/glacier/moraine shading by slope and altitude, and bake Cycles sun + AO into the terrain color texture (golden-hour sun for day, moonlight for night). Texture <= 4096 px, KTX2 or webp.
- Atmosphere: aerial-perspective haze, valley cloud layers, and Everest's summit snow plume (animated live particles). Sky: physical sky for day; stars + moon for night.
- Golden route line: the Everest Base Camp trek (Lukla, Phakding, Namche Bazaar, Tengboche, Dingboche, Lobuche, Gorak Shep, Base Camp) from OpenStreetMap trail geometry via Overpass (`geo.mjs osm s w n e`) if feasible (chain the path ways between villages); otherwise use accurate waypoints densified along the valleys. Then the South Col climbing route: Khumbu Icefall, Camp I ~6065 m, Camp II ~6400 m (Western Cwm), Camp III ~7160 m (Lhotse Face), Camp IV / South Col ~7920 m, Balcony ~8400 m, South Summit ~8749 m, Hillary Step ~8790 m, Summit 8848.86 m. Use WebSearch (cursor namespace tool) for accurate coordinates. Drape the route on the terrain with a small offset. Render it as a glowing gold tube/ribbon that draws itself with scroll progress (shader discards beyond progress), with a bright head marker and elevation labels at waypoints (drei `Text` SDF labels are fine).
- Camera: bird's-eye over the range for intro, then zoom to key trek sections per chapter:
  - values: Lukla / Namche
  - tools: Tengboche / Dingboche, with Ama Dablam as the backdrop
  - story: Gorak Shep / Base Camp / Khumbu Icefall / Western Cwm / South Col
  - voices: the summit ridge
  - outro: pull up and away, showing the whole golden route
  The camera flies a smoothed spline, never jittery, with the subject kept right of centre.
- Night variant: moonlit snow, stars, and a string of climbers' headlamps on the upper route (the real summit push happens at night).
- Cursor: the everest cursor theme (altimeter) reads `cursorBridge.elevation` (`import { cursorBridge } from "@/components/cursor/core"`). Every frame, set it to the real elevation in meters under the pointer (raycast the terrain or sample the heightmap), or null when off-terrain. Reading and writing that exported object is allowed.
- Parked mode is not used by About (no project pages), but still support mode="parked" gracefully by holding a calm bird's-eye view.
- Pano: from above Gorak Shep looking at Everest. Mini: a small carved terrain block of the Everest massif with a gold route line, on a base.
