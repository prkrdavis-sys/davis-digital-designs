# Davis Digital Designs

A portfolio that is itself a portfolio piece: every page has its own HD 3D world that you scroll through (a DNA replication bubble under the microscope, a Victorian greenhouse, the inside of a pinball machine, a snow globe, golden dunes, an accurately mapped Everest, paper planes over the clouds, and a five-scene homepage tour), each with its own themed cursor, a night version, and an optional soundscape. Five categories of work and a template shop sit on top.

## Run it

```bash
npm install
npm run dev
```

Open http://localhost:3000. Changes to code and content hot-reload.

Other commands:

| Command         | What it does                                   |
| --------------- | ---------------------------------------------- |
| `npm run build` | Production build. Also validates all content.  |
| `npm run lint`  | ESLint (React Compiler rules included).        |
| `npx tsc --noEmit` | Type-check without building.               |

## Add a project (no code required)

1. Copy `content/work/_template.mdx` to `content/work/my-project.mdx`. The filename becomes the URL: `/work/my-project`.
2. Fill in the fields at the top (the "frontmatter"). Required: `title`, `tagline`, `category`, `year`, `cover`.
3. Make a folder `public/work/my-project/` and drop in `cover.svg` (or `.png`/`.jpg`; update the `cover` path to match). 1600×900 looks best.
4. Write the story below the `---` line in Markdown.
5. Set `draft: false` (or delete the line).

If a field is wrong the build tells you the file and the field:

```
Invalid frontmatter in content/work/my-project.mdx:
  - category: Invalid enum value. Expected 'sites' | 'apps' | 'play' | 'create'
```

Fields worth knowing:

- `category`: `sites`, `apps`, `play`, or `create`. Decides which door it lives behind and which world plays behind the project page.
- `featured: true`: shows on the homepage reel.
- `size`: `sm`, `md`, or `lg`. How much room the card takes in grids.
- `tags`: become the filter chips on the category page.
- `link` + `linkLabel`: external button (live site, itch.io, YouTube).
- `problem` / `solution` / `result`: the three story cards on the project page.

## Add a shop item

Same idea: copy `content/shop/_template.mdx`. Two tiers:

- `tier: grab-and-go`: a preset template. When Lemon Squeezy is set up, add `checkoutUrl` and the button becomes "Buy now". Until then it says "Notify me" and opens the contact form.
- `tier: made-to-order`: a commission. `price` is the starting price; the button says "Commission this".

Prices are in cents (`2900` = $29).

## Turn on real email

1. Make a free account at https://resend.com and create an API key.
2. Copy `.env.example` to `.env.local` and paste the key into `RESEND_API_KEY`.
3. On Vercel, add the same variable under Project → Settings → Environment Variables.

Without a key the form still works: it opens the visitor's mail app with everything prefilled.

## Turn on Lemon Squeezy checkout

1. Create a store at https://lemonsqueezy.com, add a product, upload a PDF that contains your Canva template link.
2. Copy the product's checkout URL (looks like `https://YOUR-STORE.lemonsqueezy.com/checkout/buy/...`).
3. Paste it into that product's `checkoutUrl` in `content/shop/`.

## The 3D worlds

- **Worlds** (`src/lib/worlds.ts`): each page's palette, entrance transition, and the scene each scroll chapter plays. Page sections are marked with `data-chapter="..."` (the footer is always `outro`).
- **Engine** (`src/components/three/engine/`): one persistent canvas. The director maps scroll to chapter time, mounts the scenes that are on screen or about to be, renders each into its own HDR target with its own post-processing, and composites them with per-chapter transitions (dissolve, chroma split, frost, lens refraction, door dive, wipe), plus tone mapping, grain, and vignette.
- **Scenes** (`src/worlds/scenes/<scene>/`): one folder per world. How to build one: `src/worlds/README.md`. The DNA world is the reference.
- **Art pipeline** (`art/`): every 3D asset is generated by scripted headless Blender (models, Cycles light bakes, camera rails, Low Resources layers, posters, panoramas), then compressed with gltf-transform. Rebuild a world with `bash art/worlds/<scene>/build.sh`. Details: `art/README.md`.
- **Low Resources mode** (settings menu, gear icon): swaps each world for a 2.5D version built from Cycles depth layers. It's on by default for phones and low-memory devices, and offered automatically if the frame rate drops. Reduced motion (or no WebGL) shows the Cycles stills instead.
- **Cursors** (`src/components/cursor/`): each scene brings its own pointer, trail, click effect, and label style, drawn on a transparent overlay canvas.
- **Ambient sound** (`src/lib/ambience.ts`): synthesized soundscapes per scene. Off until you turn it on in settings.
- **Credits**: third-party data (Copernicus DEM, Sentinel-2, OpenStreetMap, PDB, Poly Haven, ambientCG) is listed in `src/lib/credits.ts` and shown in the footer.

## Design rules baked in

- One motion language: three eases, four durations, in `src/lib/motion.ts`.
- Reduced motion is respected everywhere. Touch devices get the Low Resources worlds and no custom cursor.
- No WebGL, or Low Resources mode? Each world falls back to designed poster stills and depth plates. Nothing breaks.
- Colors are CSS variables in `src/app/globals.css`. Light is day, dark is night, and each world sets its own accent trio (generated from `src/lib/worlds.ts`).
